Fellow Power

Recreate a Fellow's power using the game's runtime aggregation formula. Select the Fellow, Familiar, and Artifact, then enter account-wide bonuses from the in-game Power Details screen or other known sources.

166 Fellows 71 Familiars 99 Artifacts Browser-local presets
Formula coverage

The calculator uses the actual Fellow property formula traced from the game client. The game UI does not expose every possible runtime source, so each formula group includes editable totals and an Other / Unlisted field. Familiar milestone bonuses can require activation in-game; their calculated values are suggestions and remain editable.

Fellows with configured M1/M2/M3 rarity forms can be simulated directly. The selected form changes form-specific base Aptitude, rarity, and type data while retaining the Fellow's configured level-power growth curve.

Inheritance

Aptitude Limit Break raises basic Aptitude skill level caps. It does not directly add Fellow Power here; enter the extra Aptitude gained from those additional skill levels in the normal Skill Aptitude field.

Familiar

These five values are the Familiar contributions that actually enter Fellow power. Selecting a Familiar calculates its configured base, exclusive, and milestone bonuses; edit any value to match your account exactly.

Artifact Aptitude uses the selected Artifact's own configured Aptitude-per-level value. The base 200 level cap is informational only; higher levels can be entered when account-wide cap bonuses allow them. Artifact Power % and other reforge/aura bonuses are intentionally left to the manual Power Details inputs because the in-game Artifact stat block combines several sources.

Materia

Activate the Materia slots present on your Artifact and enter each Materia level. Materia Aptitude is calculated from its configured tier and level; click an Auto pill to switch that Aptitude value to manual.
