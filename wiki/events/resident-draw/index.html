Event Rules

◆During the event, you can use 1 item to draw prizes, which include random rewards including character fragments. The probability can be checked through the details button.

Gacha Item

◆Transcenders can obtain Gacha Items by purchasing limited bundles, completing Special Expo tasks during the event.

◆The Gach Items will be kept after event ends. Can be used in the next event.

Select Prize Pool

◆During the event, Transcenders can select or change prize pool at the event menu. There's no limits to change prize pool
