Event Rules

◆The event includes three main parts: Gift Tree, Profiteer Card, and Festival Legend.

Family Letters

◆The invited Family will send you letters during Hiemspresent regularly. The Family invited during the event will also send letters. Each Family only sends 1 letter during the event.

◆Read family letters to receive gifts from Family. Besides Crystals, Gemstone Ring, and Jewel Necklace, Transcenders can obtain extra rewards randomly including Skill Pearl, Farmstead Upgrade Blueprint, Intimacy Gachapon, Blessing Power Gachapon, Luck Stone, Basic Elixir, Advanced Hire Card, and Fairy Bottle.

◆The mailbox can store up to five unread family letters. Please wait for the next family letters after reading them all.

◆Unread family letters can't be read again after the event ends. Transcenders should be sure to read them in time in case missing out family's gifts.

Festival Memento

◆Complete certain tasks during the event to claim festival memento.

◆If Transcenders complete all tasks but don't claim the festival memento, it'll be sent to Transcenders via mail after the event ends.

Shop

◆Participate in the event to obtain event score. Exchange event scores for rewards in the shop.

◆There are multiple layers of rewards in the shop. Consume a certain number of scores to unlock new rewards.

◆Unused event scores will be converted into Crystal after the event ends. Please use the event scores in time.
