Do you often see other players' beautiful profile descriptions and want one for yourself, but don't know how to create it? Then this guide is for you

Since the text engine in our game was rewritten from the classic forum's BBCode engine, many of the text attributes are also similar. Here are most of them:

  • [color=#??????] Text [/color] – adds color to the text (choose a color from the RRGGBB color table)
  • [u] Text [/u] – underlines the text
  • [i] Text [/i] – italics the text
  • [b] Text [/b] – makes the text bold
  • [sup] Text [/sup] – makes the text superscript
  • [sub] Text [/sub] – makes the text subscript
  • [strike] Text [/strike] – strikes out the text

And the most interesting thing – the gradient 🔥

Using the [color] attribute, you can create text with a gradient within each character (not a separate color for each character, but several colors within one symbol):

  • [color=#??????,#??????] Text [/color] – two-color gradient (first from top, second from bottom)
  • [color=#??????,#??????,#??????] Text [/color] – three-color gradient (first from top left, second from bottom left, third from right)
  • [color=#??????,#??????,#??????,#??????] Text [/color] – four-color gradient (first from top left, second from bottom left, third from top right, fourth from bottom right)

Adding a fifth color doesn't work, as the text engine only sees the first four colors.

Furthermore, not long ago, there was a text size attribute [size], which the developers decided to disable.
